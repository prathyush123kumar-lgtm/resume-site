# Resume Site Documentation

Welcome to the central documentation hub for the E Prathyush Kumar Resume Website project. 

## What This Folder Contains
This directory contains comprehensive documentation covering every aspect of the project, from high-level architecture to detailed API schemas. 

## Project Overview
This is a professional, full-stack personal portfolio and resume website. It uses a modern vanilla web frontend for maximum performance (100/100 Lighthouse) and a Node.js/SQLite backend for secure contact form handling.
